# MGPUSim research paper collection

Web search and downloads: **2026-10-02**.

Collected **25 papers**, **1 slide deck**, and **9 additional records with unavailable PDFs**.

Original MGPUSim paper, predecessor, direct users/extensions, and related Akita simulation/visualization ecosystem. Not every paper that merely cites MGPUSim. This is a best-effort collection, not a claim of exhaustive coverage. Preprints and accepted manuscripts may differ from publisher versions.

Start with [MGPUSim (ISCA 2019)](2019-mgpusim.pdf), then [NaviSim](2022-navisim.pdf), [Photon](2023-photon.pdf), and [Akita](2026-akita.pdf).
